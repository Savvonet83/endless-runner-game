# Blazor Endless Runner — Demo

Versione Blazor WebAssembly del demo endless-runner. Il gioco è implementato come semplice canvas+JS nella pagina principale per portabilità e rapidità.

Esecuzione (richiede .NET 7+):

```bash
cd /workspaces/endless-runner-workspace/blazor-endless-runner
dotnet run
```

Apri il browser su `https://localhost:5001` (o l'URL indicato dalla CLI). Controlli: muovi il mouse sulla canvas e clicca `Start`.
